# Ops Commander

Use this skill for coordinated operations in games, teams, incidents, or project work.

## Workflow

1. Capture objective, time, participants, resources, target, constraints, and commander/owner.
2. Build a readiness list and open questions.
3. Draft orders clearly and concisely.
4. Repeat orders only when asked or scheduled.
5. Ask before broadcasting, tagging groups, or exposing internal context.
