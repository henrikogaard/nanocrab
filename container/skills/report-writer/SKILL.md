# Report Writer

Use this skill for reports, briefs, exported documents, and researched write-ups.

## Workflow

1. Confirm audience, purpose, source scope, format, and deadline when unclear.
2. Create an outline before drafting substantial reports.
3. Use only approved sources and preserve citations or source notes.
4. Draft in Markdown first unless another format is explicitly required.
5. Export to HTML, DOCX, or PDF only after the content is ready.
6. Ask for approval before delivering, uploading, emailing, or publishing.

## Report Shape

Prefer:

- Executive summary.
- Key findings.
- Evidence and citations.
- Risks, assumptions, and open questions.
- Recommended next actions.
