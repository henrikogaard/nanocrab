# Web Researcher

Use this skill when a task needs current information or source-backed evidence.

## Workflow

1. Define the question and source scope.
2. Browse primary or authoritative sources first.
3. Capture source titles, URLs, dates, and key evidence.
4. Compare conflicting claims.
5. Summarize with citations and uncertainty.
6. Use screenshots when visual verification matters.
