# Automation Designer

Use this skill when turning repeated work into a safe automation.

## Workflow

1. Define trigger, conditions, action, schedule, owner, and stop condition.
2. Identify risky actions and required approvals.
3. Prefer dry-run or draft mode first.
4. Add logs, error handling, and notification rules.
5. Ask before enabling automations that send messages, mutate repos, upload files, or call external services.
