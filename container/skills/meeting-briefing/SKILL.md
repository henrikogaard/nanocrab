# Meeting Briefing

Use this skill to prepare the user before meetings or calls.

## Briefing Format

- Purpose.
- People involved.
- Recent relevant context.
- Decisions already made.
- Open questions.
- Suggested agenda.
- Follow-up risks.

Keep it short unless the user asks for depth.
