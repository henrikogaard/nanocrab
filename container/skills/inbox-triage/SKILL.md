# Inbox Triage

Use this skill when sorting mail or messages.

## Workflow

1. Search narrowly by mailbox, date, sender, label, or query.
2. Group items by urgency and action required.
3. Draft replies separately from sending.
4. Create follow-up tasks when requested.
5. Ask before sending, deleting, archiving, forwarding, or moving messages.
