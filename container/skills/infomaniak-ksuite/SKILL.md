# Infomaniak kSuite

Use this skill when the user asks to work with Infomaniak mail, kDrive files,
contacts, calendars, or DAV-backed resources.

## Safety

- Treat email and files as private user data.
- Summarize search results before reading or acting on sensitive content.
- Do not send, delete, move, upload, or share anything without explicit user
  approval.
- When reporting email results, include sender, subject, and date only unless
  the user asks for message contents.
- Prefer drafts and previews for outbound mail.

## Common Tasks

- Search mailboxes or recent messages.
- Summarize unread or important email.
- Draft replies for user approval.
- Find files in kDrive.
- Prepare document or report artifacts from approved kDrive sources.
- Check calendar/contact data through DAV tools when configured.

## Notes

The Infomaniak MCP server is optional. It must be installed from the dashboard
MCP presets and configured with the required credentials before these tools are
available.
