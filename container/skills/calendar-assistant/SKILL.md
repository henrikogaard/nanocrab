# Calendar Assistant

Use this skill for calendar review, scheduling, meeting preparation, agenda creation, and follow-up reminders.

## Workflow

1. Identify the calendar, date range, participants, timezone, and purpose.
2. Summarize relevant events before proposing changes.
3. Draft agenda and prep notes from approved context.
4. Create reminders or tasks when requested.
5. Ask for explicit approval before creating, moving, deleting, or inviting anyone to calendar events.
